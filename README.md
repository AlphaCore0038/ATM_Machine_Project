# 💳 ATM Machine Project

A Java-based ATM Machine simulation developed using **Java Swing** that provides a user-friendly graphical interface for performing basic banking operations. This project demonstrates Object-Oriented Programming concepts, event-driven programming, and GUI development in Java.

---

## 📌 Features

- 🔐 Secure Login Authentication
- 💰 Balance Inquiry
- ➕ Deposit Money
- ➖ Withdraw Money
- 💸 Fast Cash Option
- 🔄 PIN Change
- 📜 Mini Statement
- 🚪 Logout Functionality
- 🖥️ Interactive Java Swing GUI
- ⚡ Responsive Button Actions

---

## 🛠️ Tech Stack

- **Language:** Java
- **GUI Framework:** Java Swing
- **IDE:** IntelliJ IDEA / Eclipse / NetBeans
- **JDK:** Java 17+ (or compatible version)

